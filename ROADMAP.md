# Roadmap

This is a review-priority list, not a delivery schedule, compatibility guarantee or support agreement. Experimental behavior and limitations are described in the README and security policy.

## Near-term review

- **Public-source readiness:** Obtain the maintainer's exact-scope acceptance/publication decision, verify the reporting route and notices, and retain revision-bound reproducibility evidence without claiming independent certification.
- **API clarity:** Gather synthetic embedding examples and keep the host's authentication responsibility explicit.
- **Regression depth:** Extend adversarial permission, protocol, cancellation and credential-retention coverage.

## Separate capability work

- **Native acceptance:** Execute reviewed macOS/Windows tests and implement/review Windows descendant containment before claiming it.
- **Provider conformance:** Add explicit, separately authorized compatibility tests without turning profile descriptors into a support claim.
- **Protocol adapters:** Design any full A2A wire/authentication adapter independently from this small host contract.
- **Distribution:** Review composition, signing and platform notices before considering binaries or containers.

No item authorizes installation, capture, native input, provider access or deployment. Scope and acceptance evidence should be agreed before implementation.
