# Changelog

This changelog describes an experimental source preview, not a stable API, support agreement, binary distribution or deployed service. The repository's actual tags and releases establish publication; preparing these entries does not itself create a version or release.

## 0.1.0-alpha.1-dev source candidate

- **Core:** Independent Go ACP transport/executor, explicit MCP configuration admission and a small in-process host contract.
- **Approval and data handling:** Correlated decisions, negative regression fixtures, bounded state and credential-aware redaction.
- **Lifecycle:** Cancellation, failure/backpressure handling and owned Unix process-group cleanup, with direct-child-only fallback disclosed.
- **Evaluation:** Synthetic agent, denial/approval/cancellation demo, standalone checks and source inventory.
- **Packaging:** Selected GitHub module path and read-only, SHA-pinned standalone workflow definitions.
- **Publication clarity:** Revision-bound validation evidence, maintainer-led acceptance and conditional confidential-reporting instructions, without changing executable behavior from the original source baseline.
